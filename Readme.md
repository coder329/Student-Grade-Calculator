# Student Grade Calculator 📊

A beginner-friendly Python project that calculates student grades using predefined grading conditions.

## 📌 Project Overview

The Student Grade Calculator takes student marks and assigns a grade using Python conditional statements.

The project also handles invalid marks, such as values below 0 or above 100.

## 🎯 Objectives

- Practice `if`, `elif`, and `else` statements
- Define clear marks ranges for grades
- Handle invalid marks
- Process multiple student records
- Display marks and assigned grades

## 🛠️ Tools Used

- Python
- Jupyter Notebook
- VS Code
- Git
- GitHub

## 📊 Grading Criteria

| Marks | Grade |
|-------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| 0 - 59 | F |
| Below 0 or above 100 | Invalid |
